NRI Club

Клуб настільних рольових ігор

Система для організації ігрових сесій, бронювання клубних кімнат та зручного запису гравців на ігри.

Ролі в системі

  • Гравець (player): переглядає доступні партії, записується на сесії та переглядає власний розклад.
  • Майстер (master): створює та проводить ігри, бронює клубні кімнати та керує учасниками.
  • Власник клубу (owner): адмініструє клубні кімнати, розклад та користувачів системи.
