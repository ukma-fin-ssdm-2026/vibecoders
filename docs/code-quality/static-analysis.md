## 2. Результати аналізу безпеки (Bandit Security Findings)

За результатами сканування **Bandit** виявлено такі потенційні загрози:

### 1. Потенційна прив'язка до всіх мережевих інтерфейсів (`B104`)
* **Локація:** `src/api/main.py:53:26` (`uvicorn.run(app, host="0.0.0.0", port=3000)`)
* **Рівень ризику:** Середній.
* **Опис ризику:** Прив'язка додатку до інтерфейсу `0.0.0.0` робить сервер доступним з будь-якої зовнішньої мережі, що може становити ризик у неконфігурованому продакшен-середовищі.
* **Рішення (Прийнятий ризик / План виправлення):** 
  * *Статус:* Свідомо прийнято для поточного етапу, оскільки додаток запускається в ізольованому локальному середовищі чи Docker-контейнері для зручності тестування командою. 
  * *План:* Перед фінальним розгортанням хост буде винесено у змінні середовища з дефолтним значенням `127.0.0.1` для локальної розробки.

### 2. Використання `assert` у тестах (`B101`)
* **Локація:** `src/api/tests/test_api.py` (рядки 15, 23, 24, 29).
* **Рівень ризику:** Низький.
* **Опис ризику:** Використання стандартних інструкцій `assert` у Python, які можуть видалятися під час компіляції в оптимізований байт-код (`-O`).
* **Рішення:** Ризик мінімальний, оскільки ці конструкції використовуються виключно в тестовому середовищі (`tests/test_api.py`) для перевірки статус-кодів API та наявності токенів.
