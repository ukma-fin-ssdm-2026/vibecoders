##  Наша команда та ролі

Проєкт виконується командою з 4 осіб

### 1. Супроводжувач репозиторію (Repo Maintainer)
**Відповідальна:** Катерина Спис (@katespys2006)
* Створення GitHub репозиторію.
* Налаштування стратегії гілкування та захисту гілок (branch protection).
* Написання початкового `README.md` з інформацією про команду.

### 2. Супроводжувач CI (CI Maintainer)
**Відповідальна:** Захарук Софія (@Sonafi3)
* Налаштування GitHub Actions CI.
* Додавання завдання тесту, що проходить (простий "Hello World" або "echo hello").
* Вставлення значка CI (CI badge) у цей `README.md`.

### 3. Керівник трекера завдань (Issue Tracker Lead)
**Відповідальна:** Голдинська Ірина (@iraholdynska)
* Налаштування міток (labels) у GitHub Issues.
* Створення початкових зразків завдань (issues).
* Документування робочого процесу завдань у репозиторії.

### 4. Керівник документації та опису проєкту (Documentation & Project Brief Lead)
**Відповідальний:** Хамаза Ігор (@reonor)
*(Для команди з 4 осіб ця роль об'єднує роботу зі статутом та описом ідеї)*
* Складання командного статуту (`TeamCharter.md`): ролі, відповідальності, комунікація та правила використання ШІ.
* Збір ідей та складання `Project-Description.md`: опис ідеї, ролі, список функцій, міні-ТЗ.
* Винесення відкритих питань обсягу в Issues та передача їх Керівнику трекера завдань.
